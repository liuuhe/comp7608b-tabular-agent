# v18：散点图与直方图接口验证

本轮补验proposal要求的两类图表。使用自建的12行合成CSV和应用默认配置，每个版本的
每项任务只运行一次。它是软件集成验证，不计入六个开发任务的三条件成绩，也不是
held-out实验或人工图表评分。所有终止失败、模型调用和成本均保留。

## 输入与检查范围

[CSV](../data/smoke/chart-types-v18/data.csv)包含study_hours、score、标识和无关字段，
有缺失值及一对重复观测。散点图应保留10个完整配对，包括重复的(8,95)；直方图应保留
11个有效study_hours值，包括score缺失的那行，4个等宽箱边界为0、2、4、6、8，
计数为3、2、2、4。无关字段的缺失不能删行。

事后用标准库CSV读取源文件，检查结果行的多重集合、实际artist数组、图表类型、
指定轴标签和分箱。预期值不送入被测模型。图像由开发者检查，不能当作独立人工评分。
程序自身的raw独立计算检查仍未覆盖；本轮外部核对不会改变原运行的验证状态。

## 显式纵轴解码

真实响应显示，散点图曾省略y；原Chart的默认value适用于聚合图，导致错误被填入规划。
新增仅用于模型解码的PlanningPlan／PlanningAnalysis／PlanningChart，要求显式提供y。
本地和历史Plan的默认值继续有效；解码结果转回普通Plan供控制器使用。省略字段的
响应被拒绝，原始JSON及实际token保存，交给已有预算内修正路径；没有自动猜测轴字段。
直方图序列化仍省略不使用的y，计算和绘图合同不变。

另外澄清原始字段和输出字段的角色，明确直方图代码返回逐条值，由绘图封装分箱；
缺失处理只看选定源字段，重复观测保留。合同错误反馈给出对应的字段和分箱说明。

修复前的6项适配器回归有3项失败：遗漏y的模型输出被接受。修复后新增9项测试覆盖
四种图表的显式字段、无效响应保留与计费、标量／澄清及计划限制；全套431项测试
通过，包含真实Docker，9.79秒；Ruff通过。两份真实遗漏y响应的
[离线回放](../evaluation/private/chart-types-v18-decoder-validation.json)均被新解码器拒绝，
实际发给模型的schema也要求y。回放不是整题恢复证据。
