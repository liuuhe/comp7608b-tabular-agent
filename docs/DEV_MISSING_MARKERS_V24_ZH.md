# v24：CSV缺失标记与处理顺序

独立复算原先只识别九种缺失标记，而且先去除空格再判断。这与数据概览和真实Docker
worker使用的pandas 2.3.3不一致：默认缺失标记按原始字段匹配，随后才去除文本两侧
空白，再把问号和空字符串设为缺失。因此，原始`NULL`、`#N/A`是缺失值，而带空格的
` NA `、` NULL `在去除空格后仍是文本。显式numeric转换可以进一步将这些文本转为空。

## 真实复现与修复

九行合成CSV同时包含上述输入、空字段、空白及问号。真实Docker返回各组的缺失数、
有效计数，以及筛选文本`NA`后的行数。旧检查器将这三张正确表全部判错，却接受了
另一次故意把两个缺失值改成文本、把带空格NA改成缺失的worker输出。

现在独立CSV实现使用固定的十九种默认标记，先按原始字段匹配，再做空白与问号处理。
实现仍使用csv和Python计算，不调用pandas求参考答案；数值推断、显式转换及后续
分析规则保留。数据概览的预处理说明和代码提示同步写明顺序，worker没有改动。
同一份已保存的两次worker输出回放后，正确版本三项通过、错误版本三项失败。
输入、代码、原始输出、修复前后判断均在
`evaluation/private/missing-markers-v24-reproduction/`。
