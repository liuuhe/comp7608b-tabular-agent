# v23：独立复算的空值排序

检查当前实现时发现，独立CSV复算对降序使用了整体反转，连同“是否为空”的排序键一起
反转，导致未定义的聚合值排在最前面。这与生成代码使用的pandas默认行为不一致，
会同时产生误拒绝与误通过，尤其影响排序后截取的top-k。

## 实际复现与修复

三组数据的均值分别为A=1、B=3、C为空。计划要求按均值降序、组名升序取第一组。
真实Docker中的pandas默认返回B；另一个明确使用`na_position='first'`的错误版本返回C。
修复前，独立检查反而拒绝B并接受C。输入、计划、代码、两次真实worker输出及检查
记录在`evaluation/private/null-sort-v23-reproduction/`，未调用模型。

现在独立复算对每个排序键分别排列非空值、将空值留在末尾，再应用输出行数限制。
稳定排序保留其他排序键的优先级和空值间的次序；不会把空值改成零或删除对应组。
生成提示与计划schema同步明确：未定义聚合值在升序、降序均排在最后，随后才取limit。
程序没有重排或改写模型输出；不符合约定的输出仍判失败，修正目标仍为code。
