## 已完成的功能

- 数据类型、缺失率、样例、统计摘要、CSV快照和哈希。
- 单表描述统计、分组比较、时间筛选、派生字段、相关和绘图。
- 容器禁网、只读输入、资源和时间限制；生成代码不会在宿主机执行。
- 从原始CSV独立重算受支持的聚合，检查有效计数、分组、排序和图表数据。
- 从原始CSV独立重算非分组 Pearson 相关与成对有效计数，明确处理常量列、空样本与筛选。
- 报告数值引用保存的结果，输出行数与原始记录数有不同的引用来源。
- 每条发现与局限都要求语义审查；计算、计划和报告分别修正并保留历史。
- 复查保留先前失败语句、理由和当前原文匹配；重算／重规划清理历史，格式重试保留独立历史。
- 单独必填的请求覆盖判断，检查遗漏的分析／回答；缺分析可重做计划，缺说明可复用计算后补写。
- 计算错误反馈具体缺失分组及少量预期／实际差异；超出计划行数的输出提早报错。
- 三个实验条件、评估脚本、盲评材料生成器、评分合并和实验设置保存／校验。
- 三条件共用的预写澄清回复协议：真实提问后在同一次运行续跑，保留问答／原计划，累计预算不重置。
- 实验批次 `--resume`：固定网格／文件／环境，保留全部终止结果与成本，阻止重复进程；部分调用停下待审计。
- 缺失数／总数的明确反例检查，以及把缺失数量标成缺失率的图表单位检查；不覆盖任意比例解释。
