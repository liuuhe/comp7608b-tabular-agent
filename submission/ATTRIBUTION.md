# Reused components and sources

This project integrates third-party software and public data. Dependency constraints are in pyproject.toml, exact resolved versions in uv.lock, and the container's runtime choices in docker/Dockerfile. Upstream software/model/data license terms continue to apply; this document does not relicense them or claim their authorship.

- LangGraph manages workflow/state; langchain-ollama and Ollama provide local model calls. Qwen supplies the base model and quantized model distribution used through Ollama. We did not train or fine-tune the model.
- pandas and NumPy implement table operations; Matplotlib produces figures; Pydantic defines schemas; Streamlit supplies the user interface; psutil samples process resources; openpyxl supports the declared table dependency. Docker provides execution isolation. Python, uv, pytest and Ruff support runtime, installation and checks. Colima supplied the Docker engine on the development Mac.
- UCI Online Retail (Daqing Chen; DOI 10.24432/C5BW33), Bike Sharing (Hadi Fanaee-T.; DOI 10.24432/C5W894) and Adult (Barry Becker and Ronny Kohavi; DOI 10.24432/C5XW20) provide the research data. Their dataset pages list CC BY 4.0. Source URLs, preprocessing, field descriptions and hashes are in data/uci/*/metadata.json and documentation.txt; full downloads are not bundled. data/demo_rentals.csv is a tiny illustrative project input, not a representative UCI sample.
- The report uses the official NeurIPS 2026 style, retained in report/latex/neurips_2026.sty. Template origin and hashes are in template-provenance.json. Pandoc and TeX Live compile the report. The official style's notices are preserved.
- The report cites ReAct, Self-Refine, LIDA and DSBench as related approaches, not as code authored by this group. Their full references are in the report sources.
- Codex and the SudoCode-provided model assisted development, writing and reference auditing as declared in AI_USE.md. Slides were prepared with Codex's document tooling. No recorded video or static historical output is represented as a live model response.

Delivered functionality is the single-table local application and its bounded checking/repair workflow. Multi-table joins, prediction, causal inference and persistent web conversation memory are not implemented. CLI prewritten clarification support was not part of the formal experiment. Same-model checks are heuristic. Historical case outputs are real saved runs, explicitly labeled; they are not mocks. Unavailable local services cause new runs to fail rather than being replaced with fabricated answers. Original private raw evidence and independent reference review are not represented as included in full.
